# 🗂️ MyStufss

> *"Um site de organização de ideias com nome generosamente criativo."*  
> *P.S.: Se já existir outro site com o mesmo nome... abafa! 😅*

## ✨ Sobre o projeto

**MyStufss** é uma aplicação Web feita para te ajudar a organizar ideias, tarefas ou qualquer coisa que venha à mente, utilizando blocos de notas.  
A proposta é simples: oferecer uma interface dinâmica e amigável, no estilo de um **Trello minimalista**, onde você pode:

- 📝 Criar blocos de notas
- ✏️ Editar blocos existentes
- 🔄 Mover blocos pela tela
- ❌ Deletar quando não fizer mais sentido

Tudo isso de forma leve, intuitiva e 100% feita com amor 💛.

---

## 🧠 Tecnologias utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias e ferramentas:

- **Python** — linguagem principal
- **Bottle** — micro framework Web que facilitou o backend
- **HTML5** — estrutura da página
- **CSS3** — estilo e responsividade
- **JavaScript** — interatividade da aplicação

## 🚀 Como rodar o projeto localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/MyStufss.git
   ```

2. Acesse o diretório:
   ```bash
   cd MyStufss
   ```

3. Instale as dependências (se necessário):
   ```bash
   pip install bottle
   ```

4. Execute a aplicação:
   ```bash
   python app.py
   ```

5. Acesse no navegador:
   ```
   http://localhost:8080
   ```
